# Trackport Android test build

This is a debug/test APK path for Android. It does not publish to a store, create a release, or sign with a release key.

## Build on GitHub

The `Trackport Android test APK` workflow runs for Android/UI changes on `main`, pull requests, and manual `workflow_dispatch`. On a successful run, download the `Trackport-Android-test-APK` artifact from the Actions run. Artifacts expire after 14 days.

The workflow builds `android/app/build/outputs/apk/debug/app-debug.apk`. It uses the debug signing key generated by Android Gradle tooling; no signing secrets are required.

## Local build

Requirements: JDK 17, Gradle 8.10.2, Android SDK platform 35, build tools 35.0.0, and NDK 27.2.12479018.

From the repository root:

```sh
python3 -m unittest discover -s android/tests -v
gradle --no-daemon --project-dir android :app:assembleDebug
```

The app bundles the existing Trackport web interface into an Android WebView and starts a Python service bound only to `127.0.0.1`. Apple Music and Spotify links are catalog metadata only. YouTube search and stream URL resolution run in the on-device service using the bundled yt-dlp package; the browser receives only search matches and downloaded audio. A user must choose a match.

The app keeps the existing 256 MiB audio import limit and MP3 encode/tag pipeline. It uses Android's document picker for imports and the system save dialog for MP3/ZIP exports. Proxy settings are stored in Android app-private preferences and every outbound service request uses the configured proxy when enabled. Proxy failures do not fall back to a direct request.

No audio is uploaded to a Trackport service. The Android service serves only the app's local UI and handles the user's requests on the device. YouTube terms prohibit downloading; this feature exists at the user's direction for their own use. Use it only for content the user has the right to download.

## Dependency versions

The build pins Chaquopy 17.2.0, Python 3.11, requests 2.34.2, PySocks 1.7.1, and yt-dlp 2026.11.23. Refresh yt-dlp deliberately when YouTube extraction compatibility requires it.
